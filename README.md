# 레슨노트

설치가 필요 없는 한국어 수업 시간표입니다. `dist/index.html`을 브라우저로 열거나 GitHub Pages로 배포하세요.

- 월간 / 주간 시간표, 30분 단위 시작 시간
- 아이 30분 / 어른 60분 자동 배정
- 수강생 이름, 연락처, 과목, 메모
- 등록당 4회 수강권, 기존 완료 회차 입력, 결제 여부, 재등록 내역
- 주 단위 반복 예약, 일정 변경, 완료/취소, 중복 및 초과 예약 방지
- JSON 백업·복원, 인쇄

## 저장 방식
입력한 정보는 사용 중인 브라우저의 localStorage에 저장됩니다. 다른 기기와 자동 동기화되지 않습니다. 브라우저 데이터를 지우기 전에 백업을 내려받으세요. 소스에는 수강생 개인정보가 포함되지 않습니다. 공용 컴퓨터에서 사용하지 않는 것을 권장합니다.

## GitHub Pages 배포
`dist/index.html`을 저장소 루트의 `index.html`로 올립니다. GitHub 저장소 Settings → Pages에서 Deploy from a branch를 선택하고 해당 브랜치의 /(root)를 지정합니다. 사이트 주소가 바뀌면 기존 데이터는 백업 파일로 옮겨주세요.

## 회차 규칙
완료 상태만 사용 횟수에 반영합니다. 예정 수업은 잔여 회차를 예약합니다. 달력의 회차는 해당 수강권 내 취소되지 않은 수업을 날짜순으로 정렬한 예정 순번입니다. 취소는 회차를 차감하지 않고, 완료를 예정으로 되돌리면 차감도 복구됩니다. 한 강사 기준으로 활성 수업의 시간 겹침을 방지합니다. 수강생 유형 변경은 새 예약에만 적용됩니다.
